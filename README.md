## Идея компании
Модный формат кинотеатра, вдохновленный эстетикой независимых французских и американских кинотеатров. Соответственно продаем билеты в кино и сопутсвующие товары. Аудитория это люди со средним и высоким доходод, для которых имеет смысл переплачивать за опыт и красивую картинку.
## Разделение обязанностей
* Морозов Егор - aнализ целевой аудитории
## Порядок и задачи файлов
* hse.csv - адреса и координаты корпусов Вышки
* metro_infrastructure.csv - парaметры релевантной для анализа инфраструктуры, координаты и названия станций метро Москвы
* moskino_data15-31.csv - расписание и информация о показах во всех точках сети Москино за период 15-31 мая
* Moskino_timetable - собирает файл moskino_data15-31.csv
* HSE_buildings_coordinates - собирает файл hse.csv
* metro_moskino - собирает данные о станция метро точек Москино
* metro_coordinates_infrastructure - собирает файл metro_infrastructure.csv
* metro_infra_duplicates - удаляет дубликаты в файле metro_infrastructure.csv
* metro_infra_kepler - добавляет нормированную колонку инфраструктуры в файл metro_infrastructure.csv
